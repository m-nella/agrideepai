# AfriDeepAI

AfriDeepAI is an agriculture and livestock AI web application built with Next.js.

## Required Vercel environment variables

OPENROUTER_API_KEY
NEXT_PUBLIC_APP_URL
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
BREVO_API_KEY
BREVO_SENDER_EMAIL
BREVO_SENDER_NAME
SESSION_SECRET

Run the contents of `supabase-schema.sql` in the Supabase SQL Editor before using accounts or cloud chat synchronization.

Never put secret values in frontend code or commit them to GitHub.
